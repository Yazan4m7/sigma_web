═══════════════════════════════════════════════════════════
   UNDERSTANDING THE OUTPUT:
═══════════════════════════════════════════════════════════

If you see:
  - Lots of files = Many changes to sync
  - Few files = Only recent changes being uploaded
  - Same file multiple times = File is being updated

File sizes help you:
  - Know what's being uploaded
  - Estimate transfer time
  - Spot unexpectedly large files
